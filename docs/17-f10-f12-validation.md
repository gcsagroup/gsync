# F10—F12：设备、同步故障与锁定验收

2026-11-06，北京时间。本轮仅使用合成数据、本机回环服务、固定 Mac App 和专用 iPhone 17 Pro Max 模拟器（iOS 26.5）。Mac 与模拟器已走通批准和撤销；指定规模的本地文件夹同步、独立附件下载和受控故障恢复通过。F12 在应用与存储层通过下列检查，系统凭据提供器在受信任宿主中的退出和取消仍随 F07 待验。没有公开部署，也没有改变 F07—F09 的剩余验收条件或实施 F13—F15。

## F10：账号与设备权限

「同步与连接 → 本地账号与设备」连接的是本机 47852 端口。自备文件夹及 WebDAV 仍不需要账号。注册、登录、退出、凭账号恢复码重置密码均有真实 HTTP 测试。服务保存加盐密码派生值、恢复码和令牌的摘要；管理会话有效期 1 天，批准的设备令牌只对本账号的指定空间有效，最长 30 天。重置会撤销全部既有会话、轮换账号恢复码，不改变保险库密码或密文。账号恢复码与保险库恢复密钥用途不同。

**实际操作。** 模拟器生成五分钟邀请，Mac 输入从模拟器独立核对的指纹并批准。仅加密回执跨端传递；模拟器接收后，还需单独输入保险库主密码，才从回环目录读到合成条目。Mac 撤销后，模拟器立即同步得到“存储或来源需要重新授权”。从模拟器共享容器取出这个空间的加密副本，在临时副本上用库密码独立解锁，仍是 1 项、1 个版本。[模拟器回读](../build/f10-f12/paired-simulator.json)

验收中修正了 iPhone 紧凑布局只选中侧栏却不进入详情的问题，也修正了 Mac 从邀请模式切到批准模式后留下旧指纹及按钮文案的问题。完整读回、撤销拒绝在 Mac (51)／模拟器 (55) 操作；最终 (60)／(61) 重新执行了生成邀请、核对、批准、回执解密、撤销和退出。服务测试还验证了旧令牌不能读取或提交新对象，其他账号不能撤销本账号的设备，过期会话被拒绝，重置后原密文保持原样。

**使用边界。** 请通过可信渠道交换邀请、指纹和回执。撤销阻止后续服务访问，不能召回旧密文、已解锁的副本或已经返回的数据。丢失设备且怀疑库密钥外泄时，还要迁移并轮换库密钥。模拟器与 Mac 共享回环开发环境；本结果不证明物理手机可连接 Mac 的回环地址。界面回归用的服务已停止。

## F11：附件、规模与故障恢复

在原生编辑器中保存的附件，达到 64 KiB 时单独加密；同步先上传正文，再发布引用。另一设备仅同步条目时不会下载正文；打开导出或生成完整备份时才取回，核对身份、认证、长度和摘要后保存加密缓存。小附件、原有内联历史和来源导入仍可内联，不批量转换旧库。完整备份会展开历史附件，缺失、损坏或超限时失败，不生成看似完整的文件。使用独立附件的空间需两端使用本轮兼容候选。

测试用了同名空文件和接近 10 MiB 的正文。第二配置首轮同步后没有附件缓存，远端主快照小于 64 KiB；截断正文时下载和备份都失败，恢复原密文后重试成功。再删除、恢复条目，独立解密完整备份，逐字节核对当前与历史正文。[核心实测](../build/f10-f12/PBsyncCoreTests-direct.log)

**规模实测。** 在本机用两个全新配置、固定 CLI 和真实文件夹存储。先导入 10,000 个收藏、5,000 条登录记录，再离线批量修改其中 1,000 条，生成并上传 1,000 个独立版本。第二配置解密读回 5,000 个条目、6,000 个版本；导出后逐条核对 5,000 个密码，其中恰好 1,000 个已更新。下表为一次运行，不是容量或性能承诺。峰值是相应 CLI 进程的最大驻留内存。

| 操作 | 耗时 | 峰值内存 |
| --- | ---: | ---: |
| 1 万收藏首次同步 | 1.004 秒 | 102.2 MiB |
| 第二配置读取 1 万收藏 | 1.415 秒 | 121.5 MiB |
| 5 千条目首次同步 | 0.602 秒 | 77.2 MiB |
| 补传 1,000 个离线版本 | 1.750 秒 | 100.6 MiB |
| 第二配置合并这 1,000 个版本 | 1.432 秒 | 99.2 MiB |
| 无新修改，再同步一次 | 1.591 秒 | 102.0 MiB |

[逐阶段测量及计数](../build/f10-f12/scale.json) · [复跑脚本](../scripts/stress-sync.py)。此测试不等同于 1,000 次独立 UI 保存。即使无变化，当前仍重读并认证全历史；大历史下它已是可测的固定成本。旧式内联附件也仍随每个历史版本进入备份。真机耗电、移动网络速度、超出测试规模的性能没有测量。

**故障实操。** 停止回环监听，真实连接失败；重启后可补传。测试服务对 PUT 返回 507 模拟配额耗尽，并在 GET 发送部分正文后断开 TCP。失败连接没有把半成品登记为新库，恢复后重新连接成功。上传中以操作系统信号杀死 CLI，重启后补传 1 个版本且无待传。迁移中在“目标已校验、旧位置尚未冻结”处杀死进程，旧位置仍可用，目标候选可用新密码独立解锁；选择另一个空目标重新迁移成功，旧客户端随后被拒绝。[故障结果](../build/f10-f12/faults.json) · [复跑脚本](../scripts/fault-sync.py)。没有断开用户网络、填满物理磁盘，或声称覆盖了所有崩溃时刻。中断产生的目标候选不会被自动删除。

## F12：锁定与敏感内容

- **剪贴板。** 改为按系统写入代次及来源空间处理，超时任务不持有复制的明文。测试使用真实、独立命名的 macOS 剪贴板：锁其他空间不清除；其他应用即使写回相同字符串也保留；只清除仍由本应用拥有的那次写入。iOS 写入保留本机限制和 30 秒系统过期时间。
- **锁定与导出。** 模拟器实际锁定选定库后，条目界面消失，空间显示“已锁定”。本地测试验证了旧编辑、确认和锁定后的再次导出均不能提交；已经由用户写到指定目的地的 CSV 仍存在，应用没有远程擦除能力。用独立目录检查合成明文标记未出现在库或同目录的文件中。加密附件导出在下载完成后会再次核对当前空间和界面会话。[应用实测](../build/f10-f12/PBsyncAppTests-direct.log)
- **凭据扩展。** 在取消、正常完成、界面消失时释放已解密状态并锁库；异步解锁返回后先检查请求是否已经失效。Mac／模拟器主程序和凭据扩展均编译并回读版本。受信任系统宿主中的真实选择、取消和退出仍需 F07 环境；这里没有将编译记为宿主验收通过。
- **错误和临时文件。** 故障脚本检查 CLI 成功／失败输出没有测试主密码或存储令牌；扫描测试的本地库目录和远端对象，没有发现被用作标记的条目密码。远端连接先在临时加密候选中完成校验，再登记；正常或可处理失败时清理候选。没有据此推断进程被强杀时所有临时文件必被删除，也没有声称证明系统统一日志、内存、交换区或已导出文件的安全擦除。
