## 项目概述

GCSA-PBsync 暂用项目目录名作为产品代号。目标是提供免费、全部开源的个人收藏夹与保险库工具：在支持的浏览器之间同步收藏夹，连接现有密码库，也允许用户迁入自有保险库统一使用。

一个 App 包含“收藏夹”和“保险库”两个独立入口。目标平台包括 Windows、macOS、iOS／iPadOS、Android，先在 Mac 和 iPhone 上完成实际验证。对外首轮试用使用 WebDAV 或本地文件夹；官方云仅在本地环境验证。

**最新范围：桌面 Firefox 纳入自动收藏夹同步；Safari 采用用户主动导入、导出，不再以 Safari 原生收藏夹自动同步作为首版发布条件。** Safari 中的自有密码库自动填充仍保留，不能与 Apple 密码库持续双向读写混为一谈。

## 如何理解文档状态

- **已确认需求**：来自本轮用户选择，是产品边界。
- **建议设计**：为完成需求提出的实现办法或默认值，可在开发验证中调整；不能冒充用户已经选定。
- **资料已核查**：官方接口或流程存在，不表示本项目已经实现。
- **待原型／真机验证**：需要可复现测试，不能在产品中宣传为已支持。
- **已实现／已验证／已发布**：分别需要代码、测试记录、分发证据；本文档交付不产生这些状态。

## 原计划的开发入口

执行开发计划的 **M0 可行性验证**：优先核查自备存储在 iPhone 上的读写、1Password／KeePass 连接、Safari 文件迁移、桌面 App 填充及 Aegis 扩展兼容。随后让收藏夹与保险库同时完成最小可用流程。

本轮按连续开发指令实现了各模块候选，但 M0 的真实平台检查和后续发布条件仍未通过。当前应按统一验收报告补齐缺口，不把可编译源码视为已跨过阶段门槛。

“全部来源纳入产品目标”不代表所有来源都能全自动读写；“完整保险库”不代表每种外部格式都能无损承载所有字段。能力必须由测试记录支撑，未通过的功能以限制说明或明确阻塞记录呈现。
