## 2. 已被替代的方案

| 早期方案／建议 | 当前结论 |
| --- | --- |
| 密码只做同步桥梁，或只以 1Password 为中心 | 两者均不足，需保留自有完整保险库 |
| 收藏夹仅同步专用文件夹 | 用户选择全量同步；Safari 文件交换例外单列 |
| 冲突需要用户选择后才继续 | 用户选择自动较新版本优先，旧版本保留 |
| 官方云先公开上线 | 先本地验证，对外试用走自备存储 |
| Mac 桌面优先要求手动操作扩展 | 优先原生接口。现有自动扩展承担原生写入未通过验收的操作 |
| 首版必须实现 Safari 原生收藏夹自动双向同步 | 用户先允许排除，随后明确可采用导入导出；以手动交换纳入 |
| 通过常在线 Mac 为 iPhone 中转 | 用户不接受，自有 iPhone 客户端独立连接存储 |
| Safari 全部功能排除 | 只限制收藏夹自动同步；手动迁移和自有密码填充保留 |
| 首轮浏览器清单未列 Firefox | 已纠正，桌面 Firefox 纳入 |

不得在后续计划中重新把已替代条件当成当前硬门槛，也不能把“允许实验性连接”解释成允许绕过系统安全或公开发布限制。

## 3. 为可执行性补充的建议

下表由助手补充，不冒充用户已逐项选择。它们主要完善数据可靠性与体验，不扩展产品方向。

| 编号 | 建议 | 原因与决定时机 |
| --- | --- | --- |
| P01 | 收藏夹与密码库分别加密、分别解锁 | 支持两入口独立使用；M0 验证密钥结构 |
| P02 | 删除进入回收站，批量操作先快照，恢复作为新版本 | 支持误删恢复与离线合并；M1／M2 落实 |
| P03 | 同 URL 在不同目录默认保留，首次合并预览 | 避免误删有意义的收藏；M3 验证 |
| P04 | 所有源数据先暂存预览，未知字段加密保留 | 避免迁移静默丢失；M3／M4 落实 |
| P05 | 自有库离线可用，前台补传，后台机会性同步 | 与手机系统调度一致；M0／M2 测量 |
| P06 | 附件按需下载，配额和保留策略可见 | 避免手机空间和免费存储失控；M4／M5 定值 |
| P07 | 生物识别便捷解锁，不替代恢复材料 | 兼顾手机与桌面使用；M0 验证 |
| P08 | 诊断脱敏，上传策略默认关闭或经明确选择 | 避免秘密进入日志；发布前定稿 |
| P09 | 首版中文优先，语言资源结构可扩展 | 本轮沟通与文档中文；不新增已承诺语言数量 |
| P10 | 成熟加密／格式库优先，复用同步核心 | 减少重复协议与自制密码学风险；M0 对比后决定 |

## 5. 风险与应对

| 风险 | 当前判断 | 应对 |
| --- | --- | --- |
| 外部库缺少持续写回 API | 高影响，尚未完全验证 | 显式能力矩阵；保留迁移；不把迁移称为同步 |
| 文件提供器与 WebDAV 并发不一致 | 高影响，需要故障测试 | 幂等、条件提交候选、历史与恢复；不能无条件覆盖 |
| 密钥与恢复设计错误 | 高影响，尚无实现 | 成熟库、跨端向量、安全审查和干净安装恢复 |
| 时钟偏差选中错误版本 | 最新优先规则的固有限制 | 因果关系、稳定顺序、异常提示和历史恢复 |
| 浏览器账号同步与本产品回环 | 待实测 | 来源映射、基线和事件去重；不默认关用户内置同步 |
| Mac 桌面 App 填充差异 | 待实测 | 逐入口验收，公开支持清单，不宣传任意软件通用 |
| 免费服务成本与维护 | 尚未进入公开运营 | 对外先自备存储，本地云测资源，不承诺无限容量 |
| 开源与商店发布安排不完整 | 尚未定稿 | 在实际发布前落实许可证、构建说明、签名与审核 |
