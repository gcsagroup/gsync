## 1. 证据等级

源码审查、自动化测试、模拟器、真机操作、签名安装、商店审核分别记录。文档检查通过只说明本文档交付质量，不证明 App 能运行或已安全。

测试使用合成数据与专用账号；不默认读取用户现有浏览器密码或真实保险库。需要真实设备或外部测试账号时记录前置条件，缺失时标记“未执行”，不能用模拟或跳过替代。

## 2. 基准与代表性样本

### 2.1 设备与环境

- Mac：型号、芯片、macOS、系统构建号、Xcode、签名身份待实机记录。
- iPhone：用户指定 iPhone 17 Pro Max；iOS 准确版本、构建号和正式／测试分支待核实。
- 浏览器：Chrome、Firefox、Edge、Aegis 和 Safari 分别记录版本及配置文件。
- WebDAV：至少一个开发服务和一种真实 NAS／兼容服务；未取得后者时不能宣称 NAS 广泛兼容。
- 文件夹：本机目录、iPhone 授权目录、至少一种能在两端访问的文件提供器，分别测试。
- 外部来源：记录 1Password、KeePass／KeePassXC 等版本、格式和密钥组合。KeePassDX 在 Android 阶段验证。

### 2.2 合成数据集

| 样本 | 内容 | 目的 |
| --- | --- | --- |
| F01 收藏夹 | 30 个网址、5 个文件夹、3 层嵌套；中文、空标题、长 URL；同 URL 不同目录与相同目录重复项 | 合并、排序、导入与去重 |
| F02 浏览器差异 | 书签栏／其他书签、两个配置文件、只读节点、并发目录移动 | 根映射和权限例外 |
| F03 基础保险库 | 12 条登录项，包含同网站不同账号、多网址、中文备注、自定义隐藏字段 | 身份匹配与密码保真 |
| F04 完整类型 | 每种非密码类型至少 2 条；TOTP 有公开测试向量，Passkey 使用专用测试站点 | 全类型存储、使用与迁移 |
| F05 附件 | 空文件、小文本、图片、同名不同内容、接近配置上限的文件 | 完整性、配额和按需下载 |
| F06 外部格式 | 由测试库实际导出的 HTML、CSV、1PUX、KDBX，以及支持的官方凭据交换 | 不能只用自写导出喂给自写解析器 |
| F07 异常输入 | 截断、篡改、未知版本、超深目录、压缩炸弹模拟、路径穿越、缺附件 | 不执行恶意内容，不覆盖有效库 |
| F08 同步压力 | 初始建议 10,000 收藏、5,000 条目和 1,000 次离线操作 | 测量首轮同步、内存、耗电和恢复；规模不是已确认容量承诺 |

F08 先在合成数据跑基线再定性能预算。不得为了达到吞吐量跳过认证、备份或字段验证。

## 5. 自动化、操作与发布检查

自动化适合格式解析、加密向量、合并性质、故障注入和后端协议。真实操作适合系统权限、扩展安装、Safari 导入、App 填充、解锁和恢复引导。两者都要有，不能用界面截图代替数据一致性检查。

界面实施后，使用 Browser／Chrome／Computer Use 等实际操作工具检查；iPhone 需真实设备操作记录。本轮已使用 Computer Use 检查 Mac 实际界面，iPhone 真机尚未验收；具体成功路径与锁定失败见统一报告。

发布前至少满足：

- 适用用例有完整通过记录；关键能力无“跳过后算通过”。
- 不存在数据损坏、秘密泄露、错误目标填充、越权写回和恢复失败。
- 一次干净安装与恢复演练通过，另一个设备能继续使用数据。
- 明确列出平台版本、来源类型及支持程度，不以导入成功代替持续连接通过。
- 签名安装、TestFlight 与 App Store 状态分别记录；没有审核结果不写“可上架已确认”。
- 自备存储无需官方账号；公开官方云入口未开放。
- 开源许可证、第三方声明、构建步骤和已知限制完整。
